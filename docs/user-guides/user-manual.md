## Getting Started

### Logging In
Navigate to your portal URL and enter your credentials. If you've forgotten your password, use the "Forgot Password" link or contact your administrator.

### Your Role
Your permissions are based on your assigned role:
- **Admin**: Full access to all features
- **Property Manager**: Manage properties, maintenance, and inspections
- **Board Member**: View reports and approve items
- **Owner/Tenant**: Limited access to relevant properties

### Navigation
Use the left sidebar to navigate between sections. The menu adapts based on your role.

## Associations

Associations represent HOA, Condo, or other community organizations.

### Creating an Association
1. Go to **Associations** → **Add Association**
2. Enter association details:
   - Name
   - Type (HOA, Condo, Co-op, etc.)
   - Address
   - Fiscal year dates
   - Tax ID (optional)
3. Add board members in the **People** section
4. Configure association settings

### Association Details
Each association has:
- **Overview**: Basic information and stats
- **Properties**: All properties in the association
- **People**: Contacts associated with the association
- **Maintenance**: Association-level maintenance requests
- **Documents**: Association documents (bylaws, CC&Rs, etc.)

### Managing Board Members
1. Go to association → **People** tab
2. Click **Add Contact**
3. Assign role: **Board Member**
4. Set board position (President, Treasurer, etc.)

## Properties

Properties are individual buildings or units you manage.

### Adding Properties
See [Setting Up Your First Property](setting-up-first-property.md) for detailed instructions.

### Property Details
Each property includes:
- **Overview**: Address, specs, occupancy
- **Units**: Individual units within the property
- **People**: Owners, tenants, vendors
- **Maintenance**: Request history
- **Inspections**: Past and upcoming inspections
- **Documents**: Leases, warranties, photos

### Units Management
For multi-unit properties:
- Add units with number, type, and specs
- Track occupancy status
- Link tenants to specific units
- Set rent amounts and lease dates

## People & Contacts

The People section manages all contacts in the system.

### Contact Types
- **Owner**: Property owners
- **Tenant**: Renters
- **Board Member**: Association board members
- **Vendor**: Service providers
- **Property Manager**: Management staff

### Adding Contacts
1. Go to **People** → **Add Contact**
2. Enter contact information:
   - Name
   - Email
   - Phone
   - Address
3. Assign role(s)
4. Link to properties or associations

### Contact Roles
Contacts can have multiple roles. For example:
- An owner might also be a board member
- A vendor might also be a tenant

### Board Positions
For board members, specify:
- President
- Vice President
- Secretary
- Treasurer
- Member-at-Large

## Maintenance Requests

Track and manage maintenance issues from submission to completion.

### Submitting a Request
1. Go to **Maintenance** → **New Request**
2. Select property/unit
3. Describe the issue
4. Set priority (Low, Medium, High, Emergency)
5. Submit

### Managing Requests
As a property manager:
1. View all requests in the Maintenance section
2. Open requests show details and history
3. Update status:
   - **Open**: New request
   - **In Progress**: Being worked on
   - **Waiting for Parts**: On hold
   - **Completed**: Finished
   - **Cancelled**: Not proceeding

### Assigning Vendors
1. Open the maintenance request
2. Click **Assign Vendor**
3. Select from vendor list
4. Vendor receives notification

### Cost Tracking
- Add estimated and actual costs
- Track parts and labor separately
- Generate cost reports by property or time period

### Escalation
For urgent issues:
1. Click **Escalate** on the request
2. Add escalation notes
3. Notification sent to management

## Inspections

Schedule and record property inspections.

### Inspection Types
- **Routine**: Regular property checks
- **Move-in**: New tenant move-in condition
- **Move-out**: Tenant move-out condition
- **Annual**: Yearly comprehensive inspection
- **Fire Safety**: Safety system checks
- **Elevator**: Elevator maintenance inspection
- **HVAC**: Heating/cooling system check
- **Roof**: Roof condition assessment
- **Pool**: Pool safety and maintenance
- **Emergency Systems**: Fire alarms, sprinklers
- **Insurance**: Insurance-required inspection

### Scheduling Inspections
1. Go to **Inspections** → **Schedule Inspection**
2. Select property/unit
3. Choose inspection type
4. Set date and time
5. Assign inspector
6. Add notes or checklist items

### Recording Results
During/after inspection:
1. Open the scheduled inspection
2. Rate each area (Excellent, Good, Fair, Poor, Critical)
3. Add notes and photos
4. Mark items requiring follow-up
5. Set overall result
6. Complete inspection

### Inspection Reports
Generate reports showing:
- Inspection history by property
- Trending issues
- Compliance status
- Cost estimates for repairs

## Reports

Generate insights from your data.

### Available Reports
- **Occupancy Report**: Current occupancy by property
- **Maintenance Summary**: Request counts and costs
- **Financial Report**: Income and expenses
- **Inspection Report**: Inspection history and results
- **Contact Directory**: All contacts with details

### Generating Reports
1. Go to **Reports**
2. Select report type
3. Apply filters:
   - Date range
   - Association
   - Property
4. Click **Generate**
5. Download as CSV or view online

### Scheduled Reports
Admin users can set up automatic report generation and email delivery.

## Approvals

Manage approval workflows for expenses and decisions.

### Approval Types
- **Maintenance**: Repair and maintenance expenses
- **Capital Improvement**: Major property upgrades
- **Vendor Contract**: New vendor agreements
- **Budget Item**: Budget changes
- **Policy Change**: Association policy updates
- **Special Assessment**: Additional fees
- **Vendor Selection**: Choosing between vendors
- **Contract Approval**: Legal contract signings
- **Capital Expense**: Large purchases

### Submitting for Approval
1. Create approval request
2. Select type and add details
3. Attach supporting documents
4. Submit to board/management

### Reviewing Approvals
Board members and admins:
1. View pending approvals
2. Review details and attachments
3. Approve, reject, or request more info
4. Add comments

- Search by name, tag, or date
